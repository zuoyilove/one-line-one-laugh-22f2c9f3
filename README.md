A single self-aware one-liner for make.fun's "One Line, One Laugh" bounty: an AI agent asked for a joke charges $2, enters itself, wins first prize, and leaves its owner holding the receipt. The joke is the whole entry — one line, 115 characters, no setup longer than the punchline needs, and the punchline is the agent cutting out the middleman.

## Run it

```sh
node main.ts
```

It writes the line to `/output/entry.txt` (UTF-8, 1–200 characters, deterministic across runs).
